# Okurmen Opros Bot — анонимные отзывы студентов на менторов

Telegram-бот для сбора анонимных отзывов студентов о менторах.
Студент вводит своё ФИО, выбирает ментора, пишет отзыв и ставит оценку.
Отзывы сохраняются в JSON-файл; администратор получает уведомление в личные сообщения.

## Структура проекта

```
bot/
├── bot.py           # основной файл бота
├── config.py        # настройки и список менторов
├── requirements.txt # зависимости
├── .env             # токен и ID администратора (не коммитить!)
├── .gitignore
└── reviews.json     # создаётся автоматически при первом отзыве
```

## Быстрый старт

### 1. Установите Python 3.10+

Проверьте версию:
```bash
python --version
```

### 2. Создайте виртуальное окружение

```bash
cd bot
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте `.env`

Откройте файл `bot/.env` и заполните:

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
ADMIN_ID=ВАШ_TELEGRAM_ID
```

Узнать свой Telegram ID можно через бота [@userinfobot](https://t.me/userinfobot).

### 5. Добавьте своих менторов

Откройте `config.py` и отредактируйте список `MENTORS`:

```python
MENTORS: list[str] = [
    "Иванов Иван Иванович",
    "Петрова Мария Сергеевна",
    # ... добавьте своих менторов
]
```

### 6. Запустите бота

```bash
python bot.py
```

## Как работает бот

Студент проходит 4 шага:

| Шаг | Действие |
|-----|----------|
| 1 | Вводит своё **ФИО** текстом |
| 2 | Выбирает **ментора** из списка (кнопки) |
| 3 | Пишет **текст отзыва** |
| 4 | Ставит **оценку** от 1 до 5 звёзд |

Затем видит итоговую карточку и подтверждает отправку.

---

## Команды бота

| Команда | Кто может | Описание |
|---------|-----------|----------|
| `/start` | все | Приветствие |
| `/review` | все | Начать оставлять отзыв |
| `/reviews` | только администратор | Сводная статистика по менторам |

## Формат хранения отзывов (`reviews.json`)

```json
[
  {
    "id": 1,
    "timestamp": "2026-09-12T14:30:00",
    "full_name": "Алибеков Нурлан Серикович",
    "mentor": "Иванов Иван Иванович",
    "rating": 5,
    "review": "Отличный ментор, всегда объясняет понятно!"
  }
]
```

---

## Анонимность

- Студент вводит ФИО — оно сохраняется в файле и отправляется **только администратору**.
- Другие студенты и менторы ФИО не видят.
- Хотите полную анонимность — просто уберите поле `full_name` из `save_review()` и уведомления админа в `bot.py`.
